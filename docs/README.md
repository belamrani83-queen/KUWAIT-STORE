# ناما للجمال | Nama Beauty - Complete Developer & AI Coder Documentation

أهلاً بك في التوثيق الهندسي والتسويقي الشامل لمتجر **ناما للجمال (Nama Beauty)** - المتجر الرائد لمكملات الجمال السريرية في المملكة العربية السعودية (DTC KSA).

تم إعداد هذا المجلد خصيصاً للمطورين ومساعدي الذكاء الاصطناعي (AI Coders) لتنفيذ وإطلاق وتوسيع المشروع بأعلى معايير هندسة البرمجيات وأعلى معدلات التحويل (CRO):

---

## 📚 فهرس ملفات التوثيق:

1. **[01_SYSTEM_ARCHITECTURE_AND_STACK.md](./01_SYSTEM_ARCHITECTURE_AND_STACK.md)**
   - المعمارية التقنية الكاملة (Frontend + FastAPI + PostgreSQL `namabeauty`).
   - خريطة مسارات API وهيكل البيانات ومخطط الجداول وتكامل Webhook مع Google Sheets.
   - معايير النشر على خادم EasyPanel.

2. **[02_BRAND_POSITIONING_AND_SAUDI_ICP.md](./02_BRAND_POSITIONING_AND_SAUDI_ICP.md)**
   - تموضع البراند الفاخر وهوية "ناما للجمال" (Nama Beauty).
   - التحليل النفسي للعميلة السعودية المستهدفة (ICP: 22–45 سنة).
   - كيف نبيع بسعر مرتفع (199 - 349 ر.س) ولماذا تفضل السعوديات السعر العالي الموثوق.
   - حل مشكلات البيئة المحلية (موية التحلية، الجفاف، المكيفات، التوتر، الأرق).

3. **[03_CRO_PRICING_AND_COD_FUNNEL.md](./03_CRO_PRICING_AND_COD_FUNNEL.md)**
   - سيكولوجية عروض الباقات المتدرجة (199 / 279 / 349 ر.س).
   - هندسة السلة الجانبية (Cart Drawer) والمبيعات المتقاطعة (Cross-Sells).
   - نموذج الدفع عند الاستلام السريع بحقلين فقط (الاسم وجوال 05XXXXXXXX).
   - نافذة الأبسل التنازلية 15 ثانية بسعر 99 ر.س لرفع الـ AOV بنسبة 40%.
   - بروتوكول واتساب لتخفيض مرتجعات وإلغاءات الـ COD إلى أقل من 8%.

4. **[04_PRODUCTS_FORMULATIONS_AND_SCIENCE_PROOF.md](./04_PRODUCTS_FORMULATIONS_AND_SCIENCE_PROOF.md)**
   - التركيبات السريرية التفصيلية للمنتجات الثلاثة:
     * علكات البيوتين ضد تساقط الشعر (10,000 مكجم بيوتين + زنك وفيتامينات).
     * مشروب الكولاجين البحري 2000 دالتون ضد التجاعيد.
     * بودرة المغنيسيوم بيسجليسينات ضد الهالات والأرق.
   - الأوزان الجزيئية، الدراسات السريرية، وشارات الاعتماد (SFDA, GMP, Lab Tested).

5. **[05_COPYWRITING_AND_KSA_DIALECT_SCRIPTS.md](./05_COPYWRITING_AND_KSA_DIALECT_SCRIPTS.md)**
   - صياغات العناوين المحفزة عاطفياً وسريرياً الموجهة للسعوديات.
   - نصوص تقييمات العملاء الواقعية بلهجة محلية عفوية ومقنعة من مدن المملكة.
   - الرد السريري على كافة الاعتراضات والمخاوف (زيادة الوزن، شعر الجسم، الضمان).
   - نصوص رسائل التأكيد والواتساب.

6. **[06_FASTAPI_BACKEND_AND_EASYPANEL_SETUP.md](./06_FASTAPI_BACKEND_AND_EASYPANEL_SETUP.md)**
   - الكود المصدري الكامل لخادم FastAPI و SQLAlchemy و Pydantic.
   - محددات التحقق من رقم الجوال السعودي.
   - كود إرسال الطلبات تلقائياً إلى Google Sheets عبر الـ Webhook.
   - ملفات Dockerfile و docker-compose لخدمة EasyPanel مع قاعدة بيانات `namabeauty`.
